# tic-tac-toe

A two-player Tic-Tac-Toe game built with React. This is my implementation of the [official React Tic-Tac-Toe tutorial](https://react.dev/learn/tutorial-tic-tac-toe), created with AI assistance.

## How to play

- Players take turns placing X and O on the 3×3 board.
- The game announces the next player, a winner, or a draw.
- Select **Play Again** to start a new round after the game ends.

## Run locally

You’ll need Node.js and npm installed.

```bash
npm install
npm run dev
```

Open the local URL printed by Vite in your browser.
